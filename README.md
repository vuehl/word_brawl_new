# 字灵 · 拆字冒险

在微信开发者工具导入**包含 `project.config.json` 的仓库根目录**，项目类型选「小游戏」，点击「编译」。根目录的 project.config.json 已指向 minigame，并沿用原项目 AppID **wx4101bd6d1ad9a61f**。启动背景底部显示百分比进度条，随玩法分包 play.js 和文本资源的实际下载、入口注册和界面初始化更新。首页成功绘制后显示 100%，下一帧收起。美术、地图和音频在用到时加载。选「以游客身份游玩」，选伙伴，然后进入森林。

## 预览与分享

在开发者工具中打开上述工程根目录，点击顶部「预览」。微信会生成当前完整游戏的临时二维码，可发给本项目有开发权限的测试人员用微信扫一扫。二维码失效时，再点一次「预览」即可生成新码。仅配置为体验成员的微信号使用公众平台「版本管理」中的体验版二维码。[微信成员与版本说明](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html)

手机复测使用本工程重新生成的「预览」码。退出当前小游戏再扫码，加载完成后进入游客页或已有存档的主页。Console 的 `[字灵启动]` 日志记录入口、启动画面提交和首页绘制的时间。

本 AppID 的预览服务实际执行 20 MiB 源码包上限。构建会校验所有提交脚本的 ES2017 语法，并为微信打包元数据预留 128 KiB。开发者工具返回的分包大小与临时预览二维码仅保存在本地 `验收/` 目录。

## 游戏与合并来源

游戏使用两份交付的原版 Three.js、森林战斗、成长、捕获和结算代码。地图覆盖三个森林区域和森林圣地。

| 内容 | 合并选择 |
| --- | --- |
| 地图与文具 | 使用文具轻量版 1.0.1 的森林物件、八类笔记本、圣地、纸面材质、脚下高度和碰撞 |
| 角色与怪物 | 使用笔画动作版 1.5 的九种主角形态、151 个角色配置、95 种原字形、101 条减字规则和狮尾圆体美术 |
| 受击与攻击 | 主角保持整字，普通投射物沿原笔画出手。怪物按原规则掉落对应笔画或部件。原来的伤害、技能与冷却由同一份战斗代码计算 |
| 运行与存档 | 微信横屏 Canvas 和 WebGL 2，使用原版触屏输入。本地文件系统保存游客状态、对局记录和备份，启动时读取已有进度 |

source 是完整的合并版桌面源码，可在该目录运行 npm start 进行对照。source/merge-report.json 记录工具包 549 个文件的合并选择及结果哈希。场景采用工具包版本，角色动画、头像和图标的 453 个同名文件采用笔画版。

## 微信工程

- minigame 是已构建的微信运行包。美术、字体、游戏数据和声音随分包提供。
- platform 是微信适配代码，负责画布、资源定位、触摸、界面绘制和本地存档。
- game.js 和 game.json 是构建入口。tools/build.mjs 将它们和当前源码写入 minigame。
- 界面复用原版按钮与逻辑。微信端按五种横屏尺寸采集控件位置，再按手机安全区和微信胶囊的位置排版。战场铺满窗口，界面文字单独按屏幕像素密度绘制。随包音乐和叫声全长保留，编码为 24 kHz、32 kb/s AAC。界面字体从随包狮尾圆体生成子集。
- 四个美术、地图、声音和文本分包通过 Brotli 压缩。首次启动按分包还原模型和词典，首次使用角色动画时按原坐标还原图片。内容哈希用于隔离资源缓存，游客存档独立保存。

## 开发和复核

直接在微信开发者工具运行已构建的项目即可。修改代码后，可从工程根目录执行下列命令。

~~~powershell
npm ci --prefix tools
node tools/build.mjs
node tools/verify-assets.mjs
node --test source/tools/lite.test.mjs
~~~

修改原始图片、音乐、字体或 JSON 后运行 node tools/build.mjs --assets 重新打资源包。这一步需要安装了 fontTools 的 Python，可用环境变量 ZILING_PYTHON 指定解释器。重新导入两份桌面交付可运行 tools/merge.py。

tools/smoke.mjs 根据 game.json 建立主包模块表，在 Chrome 的 WebGL 渲染器下从微信入口测试触摸流程，可用 CHROME_PATH 指定浏览器。测试模拟原生上下文只读的 canvas 属性，移除 Intl、Buffer 和浏览器 Base64 接口，核对进度数字和条长，再登录游客并进入森林。加 --legacy-runtime 可复测缺少椭圆、圆角矩形等绘图接口和现代 JavaScript 内建方法的环境。加 --phone-layout 可复测安全区、短横屏卡片、详情滑动、摇杆、暂停和升级选择。tools/layout-reference.mjs 可重新采集界面布局，加 --verify-only 可在隔离存档上运行合并源码的角色与场景回归。
